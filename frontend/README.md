# FixYa Frontend

Frontend React, TypeScript, Vite y Tailwind CSS del monorepo `FixYa-BackFront`.

Uso recomendado:

```bash
cd ..
docker-compose up --build
```

La URL del backend se configura con `VITE_API_URL` y por defecto apunta a:

```text
http://localhost:8000
```

Para desarrollo local sin Docker, revisa el `README.md` de la raiz del repositorio.
